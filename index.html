Human Connect — Complete App Prompt & Specification

Includes all custom UI changes, 6 tree designs, export rules & 5,000+ scalability fixes

1. Core Stack & Server

  • Frontend: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, jsPDF.
  • Backend: Node.js + Express wrapped in http.createServer(app) on port 3000 with 150mb JSON body limit and multi-project REST APIs (/api/projects, /api/family, /api/collection-links, /api/collect/:token, /api/submissions/:id/approve|reject).
  • Vite WebSocket Fix: Pass allowedHosts: true and ws: { server: httpServer } to createViteServer unconditionally (even when DISABLE_HMR=true) to prevent WebSocket closed without opened errors on hosted URLs.

2. Navigation & Upper-Right ⋮ Menu

  • Top Bar: App name + Family name on left; member count + upper-right ⋮ popover menu on right.
  • Upper-Right ⋮ Menu Sections: (1) Theme & Background (gallery image upload resized to 1400px, Clear BG, opacity slider 10%–75%), (2) Quick Tree Design (persists last selected design in localStorage), (3) App Theme (5 themes: Botanical Emerald, Royal Heritage, Ocean Sapphire, Warm Terracotta, Classic Charcoal).
  • Bottom Dock: Primary tabs (People, Tree View, Collect) + Toolbox drawer (Relate, Facts, Export PDF, Viewer & Backup).
  • Tree Bar Cleanup: Remove all Tree Design & App Theme selectors from the bottom tree bar (keep only line toggles, Bisected Couple Circles, Hide In-Laws, Manual Drag, Undo/Reset, Elder-to-Younger left/right move, Scope toggle, and Zoom/Fit).

3. All 6 Tree Designs

  • Normal Type: Top-to-bottom generation rows, 1st Gen centered, children below parents, single stem from couple ♥ badge, rectangular cards.
  • Circle Design: Exact copy of Normal Type layout, changed to circular person nodes (116px) and an attractive radial gradient background (#CCFBF1 → #DBEAFE → #EDE9FE; soft sky in PDF).
  • Circle Orbit: Concentric orbital shells (Nucleus, K, L, M...) with 360°/N spacing, recolored using Radial Fan's dark cosmic neon palette (#070D1F/#0B1530 radial backdrop, dashed spokes/stars, Cyan #22D3EE, Pink #F472B6, Yellow #FACC15, Purple #C084FC borders).
  • Dream Tree: Bottom-up tiers (Root, Bole/Trunk, Limb, Branches, Twigs) with forced Bisected Couple Circles and drag support.
  • Radial Fan: Bottom-center root fanning upward in semi-circular arcs with dark cosmic neon backdrop & header.
  • Tree Silhouette: Warm parchment #F7F4EE canvas, 210 golden-angle stipple leaves, charcoal trunk, straight branches.

4. Features: Directory, Relations, Collect & Facts

  • People Directory & Form: Instant search, Living/Late filter, paginated list, 400px photo upload/camera, manual linking for Parents, Multiple Spouses (with Divorced dashed-line flag), and Children.
  • Relationship Finder: Multi-path shortest BFS showing all connection routes through multiple marriages.
  • WhatsApp Collect & Approval Queue: Generate branch links (?collect=token), share via WhatsApp, review & edit submitted entries before approving.
  • Family Facts: 6 demographic stat cards + blood group filter + one-tap tel: directory.

5. Export & Backup + 5,000+ Member Scalability

  • Automatic Design Reuse on Export: Never ask to choose a Tree Design during PDF export—automatically use the last selected Tree Design.
  • Formats: Single-Page Tree PDF (Medium/High/Premium), Multi-Page Chart PDF, Standalone Offline HTML Viewer (Search, Relationship Finder, Blood Donors, Privacy checkboxes, HTML escaping), and Full JSON Backup (.hcbackup.json v2).
  • 5,000+ Scale Fixes: O(1) parent/spouse Map lookups, index-pointer BFS (no shift()), loop min/max (no array spreads), reserved PDF header band, proportional font/stroke minimums, skip photos below 4pt in dense PDFs, 60s URL.revokeObjectURL delay, and 300-card caps / 400-option search dropdowns in HTML Viewer.
